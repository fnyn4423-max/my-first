# できた！タッチワールド 〜自立活動サポートゲーム〜

特別支援学校の生徒向けに設計された、自立活動の学習を支援するMVP Webゲームです。  
タブレット端末（iPad等）や大型モニター、電子黒板、PCで直感的に操作できます。

🔗 **公開URL（GitHub Pages）**:  
`https://fnyn4423-max.github.io/my-first/`

---

## 🎯 自立活動の6区分との関連

| ゲームモード | 自立活動の主な区分 | 学習のねらい |
| :--- | :--- | :--- |
| **😊 きもち** | 心理的な安定 / コミュニケーション | 表情と気持ちの一致、自分の感情の表出・他者の感情の理解 |
| **🧺 なかまわけ** | 環境の把握（認知・概念） | 身の回りの物（食べ物・乗り物・道具等）の用途・共通点の理解 |
| **🎈 ゆっくりタッチ** | 身体の動き（協応・微細運動） | 目と手の協応運動、ゆっくり動く目標物の注視、画面タッチの感覚 |
| **🔢 1・2・3** | 環境の把握（見通し・系列） | 数字の順序（系列）の理解、見通しをもった行動の定着 |

## ✨ 主な特長と配慮

1. **ワンタップで遊べるシンプルなUI**
   - 大きなタッチターゲットで、指先のコントロールが苦手な生徒でも押しやすい設計。
   - スクロール不要で全画面で集中できるレイアウト。
2. **過剰な視覚刺激・プレッシャーの排除**
   - 感覚過敏に配慮した落ち着いたパステル調のデザイン。
   - 制限時間やペナルティ、減点は一切なし。自分のペースで安心して取り組めます。
3. **前向きなフィードバック**
   - 正解時には「ピンポン♪」と花丸・紙吹雪・ファンファーレで達成感を高めます。
   - 違う選択肢を選んでも不快なブザー音は鳴らさず、「もういっかい♪」と優しくリトライを促します。
4. **音声読み上げ（Web Speech API）＆効果音（Web Audio API）**
   - 外部音声ファイルへの依存がないため、オフライン・学校のセキュアなネットワークでも安定動作。
   - 問題文や褒め言葉を自動で読み上げ。文字の読みが苦手な生徒も耳から理解可能。
5. **先生・指導者向けの設定機能**
   - 画面右上の「せってい」から、効果音のON/OFF、音声読み上げのON/OFF、次の番号のガイドヒントのON/OFFをいつでも変更可能。
   - 全画面表示ボタン付きで、ブラウザのツールバーを隠して生徒の誤操作を防止。
